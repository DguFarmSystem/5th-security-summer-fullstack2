## 🛠️ 주요 구현 내용 (Features)

1. **`index.html`**:
   - **Semantic HTML5**: `<header>`, `<main>`, `<section>`, `<footer>` 등 시맨틱 태그 준수
   - **Modern Styling**: Dark Mode, Glassmorphism, CSS Grid & Flexbox 반응형 레이아웃
   - **Interactive Elements**: 호버 효과, 태그 뱃지, FontAwesome 아이콘 적용

2. **`README.md`**:
   - GitHub Flavored Markdown (GFM) 가이드라인 준수
   - 기술 스택 뱃지 및 구조도 명시
